# SAP Interactive Learning Hub

A collection of interactive visual references and learning guides for SAP technologies — built for hands-on exploration.

---

## SAP BTP (Business Technology Platform)

### [SAP BTP Solution Architect — Interactive Learning Platform](sap-btp-learning.html)

A first-principles curriculum for mastering SAP BTP as a Solution Architect. Covers the evolution from HANA Cloud Platform to BTP, the five pillars, account model and runtime architecture, key services deep dive, Clean Core development models, integration patterns, commercial models, and interactive decision tools with knowledge checks.

### [SAP BTP Administration — Interactive Learning](sap-btp-course.html)

A chapter-by-chapter course on administering SAP BTP. Walks through why BTP exists, its evolution, the account hierarchy model, runtime environments (Cloud Foundry vs Kyma vs ABAP), identity and access management, admin toolchain (Cockpit, CLIs, Terraform), and connectivity between cloud and on-premise systems.

## SAP HANA

### [SAP HANA & S/4HANA Performance Command Center](sap_performance_command_center.html)

An operational reference for SAP performance monitoring. Includes system monitoring architecture with layer-based navigation (OS, DB, ABAP, Network), a complete tool reference database, troubleshooting decision trees, an essential HANA SQL query library, critical SAP Notes reference, performance thresholds and benchmarks, and monitoring cadence schedules.

### [SAP HANA 2.0 SP8 — NSE & Partitioning Reference](hana_nse_partitioning.html)

A deep-dive technical reference on Native Storage Extension and table partitioning in HANA 2.0 SP8. Covers NSE fundamentals and deep dive, partitioning strategies, interactive decision helpers, ready-to-use implementation SQL, diagnostic monitoring queries, and INI parameter configuration reference.
