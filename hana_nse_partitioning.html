NSE — Why, What, How

WHYReduce memory costs. Keep infrequently accessed data queryable without loading it all into DRAM.
WHATA built-in warm storage tier using page-loadable columns with a disk-backed buffer cache. No extra license required.
HOWMark tables/columns/partitions as PAGE LOADABLE. Data stays on disk, pages loaded into buffer cache on demand via LRU.
P

Partitioning — Why, What, How

WHYImprove query performance via pruning, manage data lifecycle, overcome 2B row limit, enable parallel processing.
WHATHorizontal splitting of column-store tables into independent sub-tables (up to 16,000 partitions per table).
HOWDefine partition scheme (HASH, RANGE, ROUND ROBIN, or multi-level) at table creation or via ALTER TABLE.

SPS 08 Key Enhancement: Unified persistence format eliminates the slow persistence-format conversion required in SPS 04–07. Switching between COLUMN and PAGE loadable is now instant for any table size.

Buffer Cache Mechanics

How the Buffer Cache Works

The buffer cache sits in DRAM and holds recently accessed pages from page-loadable columns. Default size is 10% of total HANA memory. When a query touches NSE data:

  1. Cache hit → Page already in buffer → served at near-DRAM speed
  2. Cache miss → Page loaded from disk → placed in buffer → served
  3. Eviction → When buffer is full, LRU pages are evicted
  4. OOB Event → If buffer cannot accommodate → Out-Of-Buffer alert

Key Constraints

  • • Delta store for NSE tables always stays hot in DRAM
  • • Buffer cache cannot be pre-loaded or pinned
  • • Largest page-loadable column must fit entirely in the buffer
  • • Page sizes range from 4 KB to 16 MB
  • • Heap allocator: Pool/CS/BufferPage
  • • SPS 08: unload_threshold auto-calculated from NSE persistence size

Load Unit Inheritance Hierarchy

When a child's load unit is set to DEFAULT, it inherits from its parent. Explicit settings override inheritance.

PARTITION load unit

Prerequisites Checklist

  • HANA 2.0 SPS 04+ (SPS 08 Rev 88+ recommended for unified persistence)
  • No additional license required — included in standard SAP HANA license
  • Sufficient disk space on /hana/data (~10% more than normal for NSE metadata overhead)
  • Fast disk I/O subsystem (SSD/NVMe recommended for warm data performance)
  • NSE partitions should be smaller than 10 GB each
  • For SPS 04–07: Check persistence format via M_CS_COLUMNS_PERSISTENCE

Dynamic Range Partitioning

THRESHOLD Mode

Auto-splits the OTHERS partition when its row count exceeds the threshold value. Checked every 15 minutes (configurable).

Threshold example
CREATE COLUMN TABLE log_data (
    id BIGINT NOT NULL,
    event_date DATE NOT NULL
) PARTITION BY RANGE (event_date) (
    PARTITION '2024-01-01' <= VALUES < '2025-01-01',
    PARTITION OTHERS DYNAMIC THRESHOLD 10000000
);

INTERVAL Mode (SPS 06+)

Auto-creates partitions by time or numeric interval. DISTANCE specifies how far ahead to pre-create partitions.

Interval example
CREATE COLUMN TABLE sensor_data (
    id BIGINT NOT NULL,
    ts TIMESTAMP NOT NULL
) PARTITION BY RANGE (MONTH(ts)) (
    PARTITION '202401' <= VALUES < '202601',
    PARTITION OTHERS DYNAMIC
        INTERVAL 1 MONTH DISTANCE 12 MONTH
);

Implementation SQL

Ready-to-Use SQL

Copy-paste SQL for enabling NSE, creating partitions, and performing ALTER operations

Table Level — Enable / Revert
-- Make entire table page-loadable
ALTER TABLE "<schema>"."<table>" PAGE LOADABLE;

-- With CASCADE (propagates to all columns + indexes)
ALTER TABLE "<schema>"."<table>" PAGE LOADABLE CASCADE;

-- Create new table as page-loadable
CREATE COLUMN TABLE "<schema>"."<table>" (
    col1 INT, col2 VARCHAR(100)
) PAGE LOADABLE;

-- Revert to column-loadable
ALTER TABLE "<table>" COLUMN LOADABLE;
Column Level — Non-blocking (recommended)
-- Non-blocking column conversion (SPS 05+)
ALTER TABLE "<table>" ALTER ("<column>" ALTER PAGE LOADABLE);

-- Revert (non-blocking)
ALTER TABLE "<table>" ALTER ("<column>" ALTER COLUMN LOADABLE);
Index Level
ALTER INDEX "<schema>"."<index>" PAGE LOADABLE;
ALTER INDEX "<schema>"."<index>" COLUMN LOADABLE;  -- revert
Special — Audit Log (SPS 07+)
ALTER SYSTEM ALTER AUDIT LOG PAGE LOADABLE;
HASH Partitioning
-- Fixed partition count
CREATE COLUMN TABLE sales (
    order_id INT, customer_id INT, amount DECIMAL(10,2),
    PRIMARY KEY (order_id)
) PARTITION BY HASH (order_id) PARTITIONS 8;

-- Dynamic server-count-based
CREATE COLUMN TABLE sales (
    order_id INT, customer_id INT,
    PRIMARY KEY (order_id)
) PARTITION BY HASH (order_id) PARTITIONS GET_NUM_SERVERS();
RANGE Partitioning
CREATE COLUMN TABLE invoice (
    inv_id INT, fiscal_year INT, amount DECIMAL(10,2),
    PRIMARY KEY (inv_id, fiscal_year)
) PARTITION BY RANGE (fiscal_year) (
    PARTITION 2020 <= VALUES < 2023,
    PARTITION 2023 <= VALUES < 2025,
    PARTITION 2025 <= VALUES < 2027,
    PARTITION OTHERS
);
ROUND ROBIN Partitioning
CREATE COLUMN TABLE staging_data (
    col1 INT, col2 NVARCHAR(100)
) PARTITION BY ROUNDROBIN PARTITIONS 4;
Multi-Level (HASH + RANGE)
CREATE COLUMN TABLE transactions (
    tx_id INT, account_id INT, tx_date INT, amount DECIMAL(10,2),
    PRIMARY KEY (tx_id, account_id)
) PARTITION BY HASH (account_id) PARTITIONS 4,
    RANGE (tx_date) (
        PARTITION 20220101 <= VALUES < 20240101,
        PARTITION 20240101 <= VALUES < 20260101,
        PARTITION OTHERS
    );
ALTER Partition Operations
-- Partition an existing table
ALTER TABLE my_table PARTITION BY HASH (key_col) PARTITIONS 8;

-- Add / Drop range partitions
ALTER TABLE my_table ADD PARTITION 20270101 <= VALUES < 20280101;
ALTER TABLE my_table DROP PARTITION 20200101 <= VALUES < 20210101;

-- Enable dynamic range on OTHERS
ALTER TABLE my_table ALTER PARTITION OTHERS DYNAMIC THRESHOLD 5000000;
ALTER TABLE my_table ALTER PARTITION OTHERS DYNAMIC INTERVAL 1 YEAR;

-- Remove partitioning entirely
ALTER TABLE my_table NOT PARTITIONED;

-- Force dynamic partition creation
ALTER TABLE my_table ADD PARTITION FROM OTHERS;
Heterogeneous Partitions with Mixed Load Units
-- Current year HOT, historical WARM — the power pattern
CREATE COLUMN TABLE sales_history (
    id INT, fiscal_year INT, data NVARCHAR(500)
) PARTITION BY RANGE (fiscal_year) ((
    PARTITION 2024 <= VALUES < 2026 COLUMN LOADABLE,
    PARTITION VALUE < 2024 PAGE LOADABLE,
    PARTITION OTHERS COLUMN LOADABLE
));
Set existing partition to page-loadable
-- Move historical partition to warm storage
ALTER TABLE my_table ALTER PARTITION 3 PAGE LOADABLE;

-- Move it back to hot
ALTER TABLE my_table ALTER PARTITION 3 COLUMN LOADABLE;

-- Enable NSE Advisor statistics collection
ALTER SYSTEM ALTER CONFIGURATION ('indexserver.ini','system')

    WITH RECONFIGURE;

ALTER SYSTEM ALTER CONFIGURATION ('global.ini','SYSTEM')
    SET ('buffer_cache_cs','max_size') = '204800'

-- Set buffer cache to 15% of memory
ALTER SYSTEM ALTER CONFIGURATION ('global.ini','SYSTEM')
    SET ('buffer_cache_cs','max_size_rel') = '15'
    WITH RECONFIGURE;

-- Set eviction threshold
ALTER SYSTEM ALTER CONFIGURATION ('global.ini','SYSTEM')

Diagnostic Queries

Production-ready queries to identify NSE tables, partition details, and buffer cache health

Q1

All NSE-Enabled Tables — Full Detail

Finds tables with PAGE LOADABLE at any level (table, column, or partition) with memory, disk, and buffer cache usage.

NSE comprehensive report
WITH
nse_table_level AS (
    SELECT DISTINCT SCHEMA_NAME, TABLE_NAME, 'TABLE' AS NSE_LEVEL
    FROM TABLES
    WHERE IS_COLUMN_TABLE = 'TRUE' AND LOAD_UNIT = 'PAGE'
),
nse_column_level AS (
    SELECT DISTINCT SCHEMA_NAME, TABLE_NAME, 'COLUMN' AS NSE_LEVEL
    FROM TABLE_COLUMNS WHERE LOAD_UNIT = 'PAGE'
),
nse_partition_level AS (
    SELECT DISTINCT SCHEMA_NAME, TABLE_NAME, 'PARTITION' AS NSE_LEVEL
    FROM M_TABLE_PARTITIONS WHERE LOAD_UNIT = 'PAGE'
),
all_nse AS (
    SELECT SCHEMA_NAME, TABLE_NAME FROM nse_table_level UNION
    SELECT SCHEMA_NAME, TABLE_NAME FROM nse_column_level UNION
    SELECT SCHEMA_NAME, TABLE_NAME FROM nse_partition_level
),
nse_levels AS (
    SELECT SCHEMA_NAME, TABLE_NAME,
        STRING_AGG(NSE_LEVEL, '+') AS NSE_APPLIED_AT
    FROM (
        SELECT * FROM nse_table_level UNION ALL
        SELECT * FROM nse_column_level UNION ALL
        SELECT * FROM nse_partition_level)
    GROUP BY SCHEMA_NAME, TABLE_NAME
),
tmem AS (
    SELECT SCHEMA_NAME, TABLE_NAME,
        SUM(MEMORY_SIZE_IN_TOTAL) AS MEM,
        SUM(MEMORY_SIZE_IN_PAGE_LOADABLE_MAIN) AS BUF,
        SUM(RECORD_COUNT) AS RECS
    FROM M_CS_TABLES GROUP BY SCHEMA_NAME, TABLE_NAME
)
SELECT
    a.SCHEMA_NAME, a.TABLE_NAME,
    nl.NSE_APPLIED_AT,
    IFNULL(t.LOAD_UNIT, 'DEFAULT')       AS TABLE_LOAD_UNIT,
    IFNULL(tm.RECS, 0)                   AS ROW_COUNT,
    ROUND(IFNULL(tm.MEM,0)/1024/1024, 2)  AS MEMORY_MB,
    ROUND(IFNULL(tm.BUF,0)/1024/1024, 2)  AS BUFFER_CACHE_MB,
    ROUND(IFNULL(ps.DISK_SIZE,0)/1024/1024, 2) AS DISK_MB
FROM all_nse a
    LEFT JOIN TABLES t ON a.SCHEMA_NAME=t.SCHEMA_NAME AND a.TABLE_NAME=t.TABLE_NAME
    LEFT JOIN tmem tm ON a.SCHEMA_NAME=tm.SCHEMA_NAME AND a.TABLE_NAME=tm.TABLE_NAME
    LEFT JOIN nse_levels nl ON a.SCHEMA_NAME=nl.SCHEMA_NAME AND a.TABLE_NAME=nl.TABLE_NAME
    LEFT JOIN M_TABLE_PERSISTENCE_STATISTICS ps
        ON a.SCHEMA_NAME=ps.SCHEMA_NAME AND a.TABLE_NAME=ps.TABLE_NAME
ORDER BY IFNULL(tm.MEM, 0) DESC;
Q2

All Partitioned Tables — Summary + Per-Partition Detail

Full partition inventory with types, columns, range labels, row counts, memory, disk, and data temperature.

Partition detail report
SELECT
    tp.SCHEMA_NAME, tp.TABLE_NAME, tp.PART_ID,
    tp.LEVEL_1_TYPE, tp.LEVEL_1_EXPRESSION AS L1_COLS,
    IFNULL(tp.LEVEL_1_RANGE_MIN_VALUE, '') AS L1_MIN,
    IFNULL(tp.LEVEL_1_RANGE_MAX_VALUE, '') AS L1_MAX,
    tp.LEVEL_2_TYPE, tp.LEVEL_2_EXPRESSION AS L2_COLS,
    IFNULL(tp.LOAD_UNIT, 'DEFAULT')       AS PART_LOAD_UNIT,
    IFNULL(cs.RECORD_COUNT, 0)            AS ROWS,
    ROUND(IFNULL(cs.MEMORY_SIZE_IN_TOTAL,0)/1024/1024, 2) AS MEM_MB,
    ROUND(IFNULL(cs.MEMORY_SIZE_IN_PAGE_LOADABLE_MAIN,0)
        /1024/1024, 2) AS BUFFER_MB,
    IFNULL(cs.LOADED, '?') AS LOADED,
    CASE WHEN IFNULL(tp.LOAD_UNIT,'COLUMN') = 'PAGE'
         THEN 'WARM' ELSE 'HOT'
    END AS TEMPERATURE
FROM TABLE_PARTITIONS tp
    LEFT JOIN M_CS_TABLES cs
        ON tp.SCHEMA_NAME=cs.SCHEMA_NAME
       AND tp.TABLE_NAME=cs.TABLE_NAME
       AND tp.PART_ID=cs.PART_ID
    INNER JOIN TABLES t
        ON tp.SCHEMA_NAME=t.SCHEMA_NAME
       AND tp.TABLE_NAME=t.TABLE_NAME
       AND t.IS_COLUMN_TABLE='TRUE'
       AND t.IS_PARTITIONED='TRUE'
ORDER BY tp.SCHEMA_NAME, tp.TABLE_NAME, tp.PART_ID;
Q3

Buffer Cache Health Check

Buffer cache + OOB events
-- Buffer cache overview
SELECT CACHE_NAME,
    ROUND(USED_SIZE/1024/1024, 0)  AS USED_MB,
    ROUND(MAX_SIZE/1024/1024, 0)   AS MAX_MB,
    ROUND(USED_SIZE*100.0 / NULLIF(MAX_SIZE, 0), 2) AS FILL_PCT,
    HIT_RATIO, OUT_OF_BUFFER_COUNT
FROM M_BUFFER_CACHE_STATISTICS;

-- Out-Of-Buffer events
SELECT * FROM M_EVENTS WHERE TYPE = 'OUT_OF_BUFFERS';

-- NSE Advisor top recommendations
SELECT SCHEMA_NAME, TABLE_NAME, COLUMN_NAME,
    GRANULARITY, CONFIDENCE,
    ROUND(MEMORY_SIZE_IN_MAIN/1024/1024/1024, 2) AS SIZE_GB
FROM M_CS_NSE_ADVISOR
WHERE CONFIDENCE != '-1'
ORDER BY CONFIDENCE DESC;
